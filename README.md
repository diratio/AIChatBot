# AIChatBot

#  Telegram AI Chatbot (Google Gemini + Files Support)

Многофункциональный Telegram-бот с интегрированным искусственным интеллектом (**Google Gemini**), способный вести контекстный диалог, отвечать на любые вопросы и анализировать прикрепленные документы (`PDF`, `TXT`, `DOCX`).

---

##  Основные возможности

* **Интеллектуальный чат:** Общение с языковой моделью Google Gemini с сохранением контекста беседы (история диалога).
* **Работа с документами:** Загрузка и анализ файлов формата **PDF, TXT и DOCX** (с автоматическим извлечением текста и ограничением по размеру/объему).
* **Система Fallback (тканевая отказоустойчивость):** Автоматическое переключение между резервными моделями Gemini в случае перегрузки или сбоя основной.
* **Асинхронность:** Неблокирующая архитектура (тяжелые операции чтения файлов выполняются в отдельном потоке, бот не зависает).
* **Управление историей:** Команда `/reset` для очистки контекста текущего диалога.
* **Авторазбивка длинных сообщений:** Корректный обход лимита Telegram в 4000 символов на одно сообщение.

---

## 🛠 Технологии

* **Python 3.10+**
* **Aiogram 3.x** (асинхронный фреймворк для Telegram-ботов)
* **Google GenAI SDK** (официальный клиент для работы с Gemini API)
* **PyPDF & Python-docx** (парсинг документов)
* **Python-dotenv** (безопасное управление конфигурацией и ключами)
